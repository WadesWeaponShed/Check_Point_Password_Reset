Password requirements & compatibility

At least 6 characters, at most 128 UTF-8 bytes. For compatibility, this tool rejects *, !, backslash (\), $, #, single quotes, double quotes, line breaks, and NUL in plaintext passwords. Check the password policy on all selected targets. Check Point sk109148. These plaintext restrictions do not apply to the $ separators in a hash.

Recovery sends the plaintext password to the manager in a run-script payload. The manager may retain it in task or audit records. SIC and API access must still work. Uses newpass, then save config. This does not unlock a locked-out account or change Expert access.
